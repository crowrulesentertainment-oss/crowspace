# CrowSpace

CrowSpace is the social home of CrowRules Entertainment.

## Foundation
- Supabase authentication
- Universal CrowRules Membership
- Profiles
- Posts and likes
- Member discovery

## Planned social features
Profiles, Top 8 friends, friend requests, guestbooks, photos, music, messages, notifications, groups, events, profile themes, creator pages, and CrowPoints.
